Whenever a debugging issue is resolved, document it in `debugging-notes.md`.

Follow this format exactly:

# Debugging Notes

## Issue <Number>

### Problem

Briefly describe the observed issue or error.

### How I Investigated

Describe the investigation process, including the checks performed, logs reviewed, debugging steps taken, and any hypotheses tested.

### How AI Helped

Summarize the AI suggestions that assisted with diagnosing or resolving the issue.

### What I Validated

List the validations performed to confirm the root cause and verify the fix.

### Final Fix

Describe the final change made to resolve the issue.

Rules:
- Add new issues sequentially (Issue 1, Issue 2, ...).
- Document only issues that required investigation or debugging.
- Keep entries concise and factual.
- Focus on the debugging process and resolution rather than implementation details.
- Update the document only after the issue has been successfully resolved.
